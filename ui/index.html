Automação

Modelo que o Farol usa nas sessões autônomas (review, pushback, autoanálise). O padrão é o melhor (Opus); só troque pra Sonnet/Haiku se um dia quiser economizar o teto do teu plano. A sessão no terminal não é afetada.

Conexões

Conta primária (modo simples, uma conta), usada pra buscar e postar reviews via gh auth token. Pra monitorar mais de uma conta, use o painel Contas.
O panorama mostra todos os PRs abertos delas; o alerta é só onde você é revisor.
Nesses repos o botão Merge (em Meus PRs) fica desativado, respeitando as regras de review do time. Separe por vírgula.

Plano e chaves

Cada perfil aponta pra um diretório de config próprio. Faça claude login nesse diretório uma vez, FORA do Farol (ex.: $env:CLAUDE_CONFIG_DIR="C:\caminho"; claude login), antes de usá-lo aqui. O perfil padrão vale pra toda conta do GitHub que não tiver um perfil próprio (dropdown na conta, seção Contas). Sem nenhum perfil salvo, o Farol usa o login padrão da máquina.

Reviewers por projeto

Por repo, escolha as pessoas e times da lista (sem digitar handle na mão). É o que o botão "Reviewers" (em Meus PRs) aplica num clique.

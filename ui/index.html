Configurações

    

      

        
        
        Conta primária (modo simples, uma conta), usada pra buscar e postar reviews via gh auth token. Pra monitorar mais de uma conta, use o painel Contas no topo desta aba.
      

      

        
        
        O panorama mostra todos os PRs abertos delas; o alerta é só onde você é revisor.
      

      

        
        
        Nesses repos o botão Merge (em Meus PRs) fica desativado, respeitando as regras de review do time. Separe por vírgula.
      

      

        
        
        Vazio usa o login padrão do claude da máquina. Apontando um diretório próprio (logado em outra conta), as sessões do Farol passam a usar aquela assinatura, sem mexer no seu claude principal. Faça claude login nesse diretório uma vez antes; a conta em uso aparece em Saúde. Alternar de assinatura é trocar este caminho.
      

      

        
        

        Por repo, escolha as pessoas e times da lista (sem digitar handle na mão). É o que o botão "👥 Reviewers" (em Meus PRs) aplica num clique.

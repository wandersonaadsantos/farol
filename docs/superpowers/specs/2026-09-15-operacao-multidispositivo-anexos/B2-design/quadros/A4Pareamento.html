Farol Celular de teste

Parear este navegador

Este Farol exige credencial para abrir a API local. Nada do estado, dos relatórios, do log ou do chat aparece antes do pareamento. O código é gerado no terminal do próprio aparelho e vale uma vez, por 10 minutos.

1. No terminal deste aparelho, rode
Termux e bashnode tools/farol-parear.jsCopiar PowerShellnode .\tools\farol-parear.jsCopiar
Rode dentro da pasta de instalação do Farol. Onde fica a pasta de instalação
2. Digite o código que apareceu
Aparece na lista de navegadores pareados, para você reconhecer depois.
Parear Nenhum cookie é criado. A credencial fica guardada só neste navegador.

Perdeu o controle de um navegador pareado? No terminal: node tools/farol-parear.js --revogar-todas. Todos os navegadores voltam para esta tela.

Estados do pareamento

Código errado, com tentativas restantes
Código não confere. Restam 3 tentativas antes do bloqueio.
Código vencido
Este código passou dos 10 minutos. Gere outro no terminal e digite de novo.
Código já usado
Este código já pareou outro navegador. Cada código vale uma vez: gere um novo.
Bloqueado por tentativas
Cinco tentativas erradas. O pareamento está bloqueado até você gerar um código novo no terminal; o antigo não vale mais.
Sessão expirou ou foi revogada durante o uso
Este navegador precisa ser pareado de novo A credencial expirou ou foi revogada em outro navegador. O que você estava digitando (a mensagem do chat de acme-exemplo/app-web#42) foi guardado aqui e volta depois do pareamento.
Parear de novo
Servidor não respondeu
Não deu para falar com o Farol deste aparelho. Confira se ele está aberto no Termux e tente de novo. O código não foi gasto.
Desktop sem exigência

Nenhuma tela extra: o app abre direto no Radar, como hoje.
